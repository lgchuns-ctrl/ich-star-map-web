## 说明

1. 网页运行时不依赖官方实时接口，所有数据先归档到本地 `data/raw/`，再清洗导出为 `web/public/data/*.json`。
2. 官方公开总量仅作为校验依据，不硬编码为最终答案；如采集结果与官方汇总不一致，将输出差异报告并定位原因。
3. 采集遵守：合理 User-Agent、请求间隔、超时、指数退避、断点续传、本地缓存、失败日志、去重、原始响应归档。

## 接口参数核验结果（2026-08-06 实测）

`getProject.html` 接口各筛选参数使用数字 ID（取自官网页面 JS 的 data-id 属性）：

| 参数 | ID → 含义 |
| --- | --- |
| type | 1 民间文学、2 传统音乐、3 传统舞蹈、4 传统戏剧、5 曲艺、6 传统体育游艺与杂技、7 传统美术、8 传统技艺、9 传统医药、10 民俗 |
| rx_time | 1 第一批(2006)、2 第二批(2008)、3 第三批(2011)、4 第四批(2014)、10 第五批(2021) |
| cate | 1 新增项目、2 扩展项目 |
| province | 省级行政区代码；特殊值：990121 中直单位、990122 新疆生产建设兵团、810000 香港、820000 澳门 |
| category_id | 16 = 国家级非遗项目栏目（固定） |
| limit / p | 每页条数与页码；limit 实测支持 100 |

实测总量：category_id=16 全量 3610 条（地区子项口径）；type=1（民间文学）251 条；cate=2（扩展项目）1332 条；rx_time=10（第五批）465 条；province=110000（北京市）120 条。

注意事项：传中文名称作为 type/cate/province 会导致接口返回异常数据集（如 4234 条、字段缺失），必须使用数字 ID。
