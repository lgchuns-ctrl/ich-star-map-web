# 网页设计说明（试点 MVP）

## 一、视觉体系

设计关键词：非遗、星图、档案、时间、地域、文化传承、数字人文、现代东方。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 背景层级 | `#0b101a / #101826 / #16202f` | 夜空-档案纸底 |
| 主色 | `#d9b877`（鎏金） | 强调、图表高亮 |
| 辅助色 | `#c2452e`（朱砂）、`#5a9e8b`（青玉） | 警示/注释、辅助数据 |
| 十类别色 | `--c-cat-1..10` | 十大类别配色（后续阶段启用） |
| 字体 | Serif 标题（思源宋体/宋体）+ Sans 正文 | 文化档案感，保持可读 |
| 圆角/阴影 | 10px / 大阴影 | 卡片系统 |

不使用：廉价大屏风、纯科技蓝、过量发光、无意义粒子、旋转 3D 地球、低可读古风字体、固定 1920×1080 布局。

## 二、页面结构（MVP 已实现）

1. **首页**：标题、核心介绍、数据更新时间、关键指标（从 metadata.json 动态读取）、星空背景、滚动提示、数据来源入口。
2. **全国分布**：省级地图（ECharts + 本地 GeoJSON）、悬浮提示、点击联动、类别/批次/类型/地区筛选、地图图例、省份列表、数据口径说明。
3. **寻找一项非遗**：关键词搜索（名称/编号/保护单位/地区）、类别/批次/类型/地区筛选、分页结果表、项目详情抽屉。
4. **数据与方法**：数据版本、数据来源、采集/清洗流程、指标定义、研究限制、免责声明。

后续阶段将加入：五批名录演化时间轴、十大类别星系、传承资源观察、省份对比实验室、图表数据下载、分享/海报导出评估。

## 三、交互设计

- 地图点击/悬浮联动省份列表与筛选；
- 所有筛选即时生效，显示“当前筛选条件”并可一键重置；
- 空状态/加载状态/错误状态均有明确文案；
- 移动端：图表高度自适应、表格横向滚动、导航紧凑模式；
- 路由使用 hash 模式 + 相对资源路径，刷新与子目录部署均可用；
- 图表不依赖在线接口，全部本地 JSON + 本地 GeoJSON。
