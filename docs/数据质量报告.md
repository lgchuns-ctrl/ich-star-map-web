## 四、试点发现（数据层面）

1. 民间文学门类共 251 条地区子项，对应 167 个独立项目编号——项目与子项是 1:N 关系，不能混用两个口径。
2. 跨地区项目典型：格萨(斯)尔覆盖 8 个省级地区（含中直单位）、董永传说覆盖 5 省、梁祝传说覆盖 4 省。
3. 五批均有新增与扩展；第一批仅新增（53 条），第二批开始出现扩展（9 条）。
4. 地区分布（试点范围内）：山东省 27、浙江省 24、湖北省 21、新疆维吾尔自治区 19、云南省 19 领先。

## 五、数据限制与尚未解决的问题

1. 试点仅覆盖民间文学门类，统计不能外推到全国。
2. 传承人公开名单尚未采集（阶段C），传承资源指标暂以函数与测试就绪，未产出真实值。
3. `keywords` 服务端检索不稳定，前端本地搜索代替。
4. 保护单位标准化仅做格式清洗；疑似同一单位的合并需进入人工核验清单（全量阶段）。
5. 与官方汇总的差异校验将在全量阶段执行：官方口径 1557 项 / 3610 子项仅作校验依据，不硬编码。
