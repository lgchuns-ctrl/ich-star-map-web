# 答辩演示脚本（初稿）

> 三分钟演示路线：首页 → 全国地图 → 时间演化 → 类别分布 → 省份对比 → 传承资源观察 → 项目搜索 → 数据与方法
> 注：时间演化、类别星系、省份对比、传承资源观察页面将在阶段 D/E 上线，脚本先行。

## 开场（15 秒）

大家好，这是我们团队的数字人文作品《非遗星图》。它把五批国家级非物质文化遗产名录公开数据整理成一张可交互的“星图”，让每个人都能直观看到：非遗分布在哪里、类别如何演化、传承资源覆盖如何。

## 首页 → 全国地图（45 秒）

（打开首页）首页的核心数据全部来自我们采集并清洗的真实公开数据，版本与更新时间可见。（进入全国分布）这是中国省级地图，颜色深浅代表地区子项数量。点击省份可以查看该省的项目、子项、类别覆盖与新增/扩展构成；类别、批次、类型筛选即时联动。

## 自定义观察（语音意图驱动，45 秒）

（进入自定义观察区块）这是我们最想重点展示的交互创新：不用学操作，直接说或输入你想看什么。比如对着网页说“对比浙江和山东的传统技艺”，系统自动解析意图——地区：浙江、山东，类别：传统技艺——并立即生成一张两省对比图。问“哪个省份民间文学的子项最多”，它生成地区排名；问“传统戏剧五批的变化”，它生成批次趋势；问“民间文学在全国的分布”，它高亮地图。每一次生成都透明显示解析结果、数据口径与免责声明，并且可以一键导出图片和数据。全部基于本地真实数据，断网也能用。

这里要特别说明一个口径：我们区分“独立项目”和“地区子项”，例如“格萨(斯)尔”覆盖 8 个省级地区，不能把申报记录误算成 8 个项目。

## 时间演化（30 秒）

（阶段E演示）五批名录从 2006 到 2021，新增与扩展各自演化；地图按批次播放，展示非遗名录的空间扩散过程。

## 类别分布（30 秒）

（阶段E演示）十大类别以“星系”呈现：每个类别展示项目数、地区分布、批次变化与代表项目，说明不同类别的空间与时间特征。

## 省份对比与传承资源观察（40 秒）

选择两个省份，系统自动对比项目数、类别结构与批次构成。传承资源观察使用两个透明指标：代表性传承人覆盖率、每百个子项对应传承人数，并同时展示分子、分母与数据限制。我们明确声明：这些指标只反映公开数据中的配置情况，不代表官方濒危等级。

## 项目搜索与数据方法（20 秒）

“寻找一项非遗”支持名称、编号、地区、保护单位搜索。最后，“数据与方法”页展示了数据来源、采集流程、质量报告与研究限制，保证每一项结论都可追溯。

## 结尾（10 秒）

《非遗星图》希望用数据让非遗“可见”。谢谢大家！

## 答辩 PPT 大纲（建议）

1. 为什么做（非遗公开数据分散，缺乏直观认知入口）
2. 数据从哪里来（ihchina 公开接口 + 国务院/文旅部公文校验）
3. 数据如何清洗（编号/地区/批次标准化，双口径，人工抽样）
4. 发现了什么（试点：跨省项目、批次结构、地区分布）
5. 网站如何交互（地图联动、筛选、搜索、对比 + **语音/文字意图驱动的定制图表**）
6. 技术如何实现（Python 管道 + Vue3/TS/ECharts + 本地意图解析 + GitHub Pages）
7. 有什么创新（语音意图驱动可视化、双口径、透明指标、可追溯）
8. 有什么文化价值（数字人文、非遗传播）
9. 有哪些局限与后续计划
