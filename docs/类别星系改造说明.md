# 类别星系（十类非遗星系）3D 改造说明

> 状态：2026-08-07 已完成两级宇宙探索系统改造（见文末“改造后状态”）。

> 范围：只改造「类别星系 / 十类非遗星系」的 3D 展示组件及其专属样式/工具函数。
> 明确不动：其他页面模块、导航、首页、全国分布、批次演化、传承资源、省份对比、寻找非遗、数据与方法、数据采集/清洗/JSON 结构、全局主题。

## 一、当前实现（改造前）

- 组件：`web/src/components/CategoryGalaxy3D.vue`（Three.js，WebGL 不可用时回退到 `CategoryGalaxy.vue` 2D 星图）。
- 数据：`store.dataset.subitems` 的 3610 条地区子项，一次性全部生成 3610 个 3D 数据粒子，按十大类别聚成 10 个星团。
- 视觉：PointsMaterial 使用 AdditiveBlending + 较亮颜色 + 大光晕 Sprite；无 UnrealBloomPass。
- 交互：鼠标拖拽/滚轮（球坐标阻尼）、MediaPipe 手势（转手/握拳/五指）、点击类别星团 → 飞入 + HTML 详情面板。

## 二、当前存在的问题

1. 3610 个数据粒子在总览同时显示，叠加后亮度爆炸、大片纯白；
2. 十个类别中心相互重叠，缺乏空间层次（像“十团烟花”）；
3. 标签直接绘制在 Canvas 上，尺寸/透明度失控，互相遮挡；
4. 点击后只有简单缩放，缺少“进入另一个世界”的连续镜头；
5. 用户无法理解“总览=十大类别 / 进入=具体子项”的两级结构。

## 三、改造方案（两级宇宙探索系统）

### LEVEL 1 —— 宇宙总览

- 深空背景三层：远景恒星（细小、暗、轻微闪烁）+ 中景星尘（缓慢漂浮）+ 极淡星云 Sprite（Opacity ≤ 0.1）；
- 只显示 10 个类别天体（核心 + 装饰星尘 + 极淡 Halo + HTML 标签：类别名 + 子项数）；
- 天体大小按子项数做 sqrt 压缩映射，最大/最小直径比控制在约 1.3–1.8；
- 10 个天体分布在不同 X/Y/Z 深度（前景/中景/远景），负空间充足；
- 相机限位（水平/垂直/缩放范围），鼠标移动产生轻微视差；
- Hover：天体微亮、Halo 微扩、星尘加速、标签高亮、其他类别降 Opacity、极简 Tooltip；
- 颜色：本地专属低饱和宇宙色板（雾蓝/暗紫/柔金/青绿/月白…），不做纯色球体。

### LEVEL 2 —— 类别内部星系

- 进入某类别后，才加载该类别对应的真实地区子项粒子（1 子项 = 1 数据粒子，不产生虚假粒子）；
- 子项按省份形成局部星群（每省一个极淡 Anchor + 围绕分布）；
- 粒子颜色默认按公布批次（2006/2008/2011/2014/2021 同色系渐变），可切换为按省份；
- Hover 粒子显示极简 Tooltip（项目名/编号/申报地区/批次/新增扩展/保护单位），点击复用现有 `ProjectDetailDrawer`；
- 左上/右上克制信息面板：类别名、子项数、省份数、首次/最近批次、按省份/按批次切换。

### 相机飞入与返回

- 点击类别 → 1.8s 平滑飞入（easeInOutCubic，同时动画相机位置/目标/FOV）；其他类别逐渐淡出远离；近景时装饰星尘向外扩散，随后数据粒子淡入；
- 返回按钮 → 反向动画：数据粒子收拢 → 相机退出 → 其他类别恢复；
- 全程空间连续，无硬切换。

## 四、Bloom / 过曝控制

- 不引入 UnrealBloomPass（避免额外开销与失控叠加）；
- 使用 `ACESFilmicToneMapping` + 合理 `toneMappingExposure`；
- 常规粒子使用 NormalBlending + 低 Opacity（0.45–0.7）；只有极小核心光点使用 AdditiveBlending；
- 天体核心少量近白亮点，Halo 为透明渐变（Alpha ≤ 0.1），整体目标是“夜空中的星星”而非“白色 LED”。

## 五、LOD 与性能

- 总览只渲染：10 个核心 + 装饰星尘 + 背景（数据粒子不创建）；
- 详情只渲染：当前类别数据粒子 + 该类别装饰 + 背景；
- 数据粒子全部走单个 `THREE.Points`（BufferGeometry），不创建 3610 个 Mesh；
- Picking：总览用核心代理球 Raycaster；详情用 `Raycaster` + Points 阈值拾取；
- 单一 rAF 循环；离开/卸载时 dispose 所有 Geometry/Material/Texture、停止摄像头与监听，防内存泄漏。

## 八、验收要点

总览仅 10 个天体、无白色曝光、标签不重叠、有视差；点击平滑飞入；详情仅当前类别真实子项、按省份成簇、按批次着色；Hover 有 Tooltip、点击打开现有详情抽屉；可平滑返回；其他模块无回归；type-check / build 通过；控制台无错误；无内存泄漏。

- 飞入：点击天体 → 1.8s easeInOutCubic 相机飞入（位置/目标/FOV 同步），其他天体淡出，近景时装饰星尘轻微扩散；

## 十、方向修正（2026-08-07 第二阶段：彻底改为 2D 星云）

用户明确否决上一版“3D 星球”方向，要求**彻底改为 2D 星云数据可视化**：

- 删除：3D 星球/PerspectiveCamera/OrbitControls/拖拽旋转/滚轮/手势识别/“开启手势控制”按钮/白色发光球/大 Bloom/左上角统计列表；
- 目标视觉：铺满整个展示区的 2D 深空星系——深蓝黑渐变 + 远景恒星 + 大尺度蓝紫星云 + 星尘 + 3610 个真实数据星点 + 十大类别星云区域与标签，整体像“一张活着的宇宙知识地图”；
- 数据布局：10 个类别是同一座银河中的 10 个星云区域（椭圆/旋涡/带状等不规则轮廓，Gaussian + Noise + 旋涡扰动），中央较密集、边缘衰减，彼此由星尘自然连接，不再是十个孤立圆球；
- 数据：1 地区子项 = 1 数据星点（dataParticles），装饰粒子（decorativeParticles）仅用于背景星云，两者严格分离；固定随机种子（按 category/project_code/subitem_id），刷新后位置稳定；
- 颜色：深蓝/青蓝/靛青/紫蓝为主，十大类别低饱和 Accent（暖金/紫蓝/青绿/暗红紫/柔橙/蓝青/玫紫/金青/浅青绿/淡紫），星云内部=核心色+蓝色环境色+少量白色高光；
- 粒子规格：0.5–1.4px 为主，少量 2–3px，极少数 4px；透明度 0.15–0.8；无大面积白色 Glow；
- 交互（后续阶段）：仅 Hover + Click；点击类别 → 2D 地图式平滑 Zoom（Scale+Translate 1–1.5s）→ Detail 展开省份星群 → Hover 数据点 Tooltip → 点击复用 ProjectDetailDrawer → 返回动画（1–1.2s）；
- 背景在 Overview/Detail 中持续存在；页面容器位置/宽高/圆角不变；移动端点击进入、仅显示类别名称。

实施顺序：第一阶段只做静态 Overview 视觉（本次），验收截图后再做交互。

## 十一、方向再次明确（2026-08-07 第三阶段：2.5D 固定视角宇宙图）

用户进一步明确：不要纯 2D 散点图，也不要自由 3D；要**2.5D / 浅层 3D / 固定视角宇宙图**——

- 十个类别星团分布在**同一个银河主平面**上（整体围绕式构图，中心：传统技艺、民俗；周围：其余八类），带轻微前后层次（z 差 ±0–38）与弱透视（F=1500），画面有景深感但**相机固定**；
- 取消：OrbitControls、手势、拖拽旋转、滚轮缩放、左上角统计列表；仅保留极轻微鼠标视差与缓慢背景呼吸；
- 背景（装饰层）与数据层严格分离：decorativeStars / decorativeNebula / decorativeDust 只做宇宙质感，数据粒子（3610 个真实地区子项）只存在于十个类别星团内部；
- 星团形态：Anchor 核心 + Halo + 云状/椭圆/弧形/带状粒子分布 + 边缘衰减 + 少量高亮星，非实心球；
- 渲染：Canvas 2D + 固定弱透视投影（盘面倾斜 TILT=0.3），无 Three.js 依赖；
- 静态 Overview 验证：10 标签、星团位置围绕分布、scale 0.984–1.064（深度层次）、视差生效、97.8% 画布有内容、白色过热 0%、控制台 0 异常；
- 后续 PHASE 2-5：Hover 高亮 + Tooltip → 点击 2D 平滑放大进入 → 类别内部粒子（省份星群/批次色）Hover/Click 接回详情抽屉 → 返回动画。
