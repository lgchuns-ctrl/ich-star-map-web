# 网页设计说明

## 一、视觉体系

设计关键词：非遗、星图、档案、时间、地域、文化传承、数字人文、现代东方。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 背景层级 | `#0b101a / #101826 / #16202f` | 夜空-档案纸底 |
| 主色 | `#d9b877`（鎏金） | 强调、图表高亮 |
| 辅助色 | `#c2452e`（朱砂）、`#5a9e8b`（青玉） | 警示/注释、辅助数据 |
| 十类别色 | `--c-cat-1..10` | 十大类别配色（后续阶段启用） |
| 字体 | Serif 标题（思源宋体/宋体）+ Sans 正文 | 文化档案感，保持可读 |
| 圆角/阴影 | 10px / 大阴影 | 卡片系统 |

不使用：廉价大屏风、纯科技蓝、过量发光、无意义粒子、旋转 3D 地球、低可读古风字体、固定 1920×1080 布局。

## 二、页面结构（单页长滚动，2026-08-06 升级）

全站采用**单页上下滑动**的信息架构，顶部导航栏通过锚点快速定位并在滚动时高亮当前区块：

| 区块 | 内容 |
| --- | --- |
| 首页 | 星空 Hero、动态数字指标、研究问题、作品特点 |
| 全国分布 | 省级地图（指标可切换）、多条件筛选、省份列表、详情抽屉 |
| 批次演化 | 新增/扩展堆叠柱 + 累计线、批次×类别堆叠、省份×批次热力图 |
| 类别星系 | 十类别彩色卡片、类别规模分布、传承人覆盖率对比 |
| 传承资源 | 指标卡、TOP15 柱状图、省级/类别表格、指标解释 |
| 省份对比 | 双省选择、对比数据卡、类别雷达、批次对比、数据差异摘要 |
| 寻找非遗 | 关键词搜索、多维筛选、分页结果、项目详情抽屉 |
| 数据与方法 | 数据版本、来源、流程、指标、限制、文档 |

图表按需懒加载（滚动进入视口才初始化），减少首屏开销。

## 三、交互设计

- 地图点击/悬浮联动省份列表与筛选；
- 所有筛选即时生效，显示“当前筛选条件”并可一键重置；
- 空状态/加载状态/错误状态均有明确文案；
- 移动端：图表高度自适应、表格横向滚动、导航紧凑模式；
- 使用原生锚点定位（#map、#timeline 等）+ 相对资源路径，刷新、深链与子目录部署均可用；
- 图表不依赖在线接口，全部本地 JSON + 本地 GeoJSON。

## 四、动效与交互细节

- 指标数字进入视口后滚动递增（AnimatedNumber）；
- 卡片/文字随滚动滑入，支持上滑、左滑、右滑三种方向与错峰延迟（Reveal + delay）；
- 首页 Hero 标题/副标题/按钮逐级上浮入场（rise 动画）；
- 柱状图/堆叠图/热力图在进入视口时由 0 生长或渐显（图表懒加载 + ECharts animation）；
- 卡片悬停上浮 + 金色描边 + 阴影（hoverable）；
- 全局鼠标跟随微光（MouseGlow，触屏设备自动关闭）；
- 星空背景、滚动提示箭头、导航滚动高亮（scrollspy）。

动效保持克制，不以牺牲数据可读性为代价；支持 `prefers-reduced-motion` 时星空动画静态化。

## 六、说明与免责声明位置
