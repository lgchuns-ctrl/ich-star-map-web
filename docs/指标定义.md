# 指标定义（传承资源观察）

> 所有指标均基于**公开**国家级名录与国家级代表性传承人数据，仅反映公开数据中的资源配置与覆盖情况，不代表官方濒危等级或保护成效评价。

## 1. 代表性传承人覆盖率

```text
覆盖率 = 已匹配到国家级代表性传承人的项目或子项数量 ÷ 对应项目或子项总量
```

- 分子、分母必须同时展示；
- 分母为 0 时显示“无法计算”而非 0；
- 展示缺失情况与数据限制。

## 2. 每百个子项对应传承人数

```text
每百个子项对应传承人数 = 国家级代表性传承人数 ÷ 地区子项数量 × 100
```

## 3. 类别覆盖度

```text
类别覆盖度 = 已覆盖类别数 ÷ 十大门类总数
```

## 4. 不使用未经论证的综合分数

本项目不构建综合“濒危分数”。如后续提供“综合关注度”，必须：使用透明权重、提供权重解释、允许关闭综合分数、明确声明非官方评价。

## 5. 口径说明

- **独立项目**：按项目编号去重；
- **地区子项**：项目在不同申报地区的记录；
- 试点阶段仅覆盖民间文学门类，任何指标必须先声明数据范围。
