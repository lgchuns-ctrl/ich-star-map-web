# 语音交互定制可视化方案（突破方向）

> 指导老师反馈：作品整体不错（国赛二等奖水平），突破方向是**交互**——用语音输入把意图描述清楚，系统生成定制化可视化。

## 一、功能定义

用户对着网页说出/输入一句自然语言（如“对比浙江和山东的传统技艺”、“哪个省份民间文学子项最多”、“看看五批名录里传统戏剧的变化”），系统自动：

1. 解析意图与要素（地区、类别、批次、指标、操作、维度）；
2. 从本地真实数据计算；
3. 生成一张定制图表 + 标题 + 数据口径 + 来源 + 免责声明；
4. 支持继续追问/换说法重新生成。

## 二、产品形态

- 页面新增「**自定义观察**」区块（锚点导航），含：麦克风按钮、输入框、示例问题卡片、生成结果面板；
- 结果面板展示：用户原话 → 解析结果（结构化意图）→ 图表 → 口径说明；
- 语音识别不可用/断网时自动降级为文字输入，核心“意图→图表”功能完全离线可用。

## 三、技术约束

- **不依赖在线 AI 接口**（无密钥、比赛断网可用）→ 意图理解用本地规则引擎；
- 只使用本地 JSON 数据，图表可追溯到原始记录；
- 语音识别使用浏览器 Web Speech API（Chrome/Edge 支持中文，需联网调用系统识别服务；无网络时走文字输入）；
- 新增依赖最小化，避免影响构建体积与离线性。

## 四、任务清单

> 进度：2026-08-07 完成 **MVP + 模板扩充 + 导出 + 分享/海报**：
> 意图解析引擎（本地规则，80 项单测）、文字输入 + 语音识别（Web Speech API，自动降级）、6 个模板（双省对比/类别分布/地区排名/批次趋势/地图分布/传承资源对比）、结果导出图片/数据/海报、分享链接（URL ?q= 自动加载）、「自定义观察」区块与导航锚点。待办：视频演示材料、更多边界口语。

## 五、风险与取舍

| 风险 | 对策 |
| --- | --- |
| 语音识别需联网/浏览器支持 | 文字输入兜底，核心价值仍在；页面明确提示 |
| 规则引擎覆盖有限 | 首批收敛 7 类模板 + 示例引导 + 解析结果回显，逐步扩充词典 |
| 意图理解不完美被评委追问 | 展示“解析回显”透明机制，说明本地离线设计是数据伦理/断网要求的主动选择 |
| 新增代码量影响交付节奏 | 按阶段推进，先出可用 MVP（文字+3 模板），再扩语音与更多模板 |

## 六、预期创新点表述

- 把“数据可视化”升级为“**意图驱动的数据问答可视化**”：口语化描述 → 自动抽取要素 → 本地真实数据计算 → 定制图表；
- 透明可解释：用户能看到系统解析出的意图结构，图表附口径与免责声明；
- 离线优先：不依赖在线 AI 接口，符合比赛断网演示要求与数据伦理。
