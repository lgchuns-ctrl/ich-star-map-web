# 部署说明

## 一、本地运行

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm run preview    # 预览构建产物（需先 npm run build）
```

## 二、GitHub Pages 部署

1. 将仓库推送到 GitHub；
2. 仓库 Settings → Pages → Source 选择 `GitHub Actions`；
3. 仓库内已包含 `.github/workflows/deploy.yml`：在 push/手动触发时构建 `web/dist` 并发布到 `gh-pages`。

## 三、非根路径支持

- `vite.config.ts` 中 `base: './'`，资源相对路径加载；
- 路由使用 hash 模式（`createWebHashHistory`），任意路径刷新均可用；
- 数据通过相对路径 `./data/*.json` 加载，不依赖服务器路径配置。

## 四、离线能力

- 网页运行时不调用任何在线接口；
- 数据、地图 GeoJSON、样式全部打包/随静态资源发布；
- 断网时核心功能（地图、筛选、搜索、详情）仍可用。

## 五、验证命令

```bash
python -m pytest tests -q                 # Python 数据管道测试
cd web
npm run type-check                        # TypeScript 检查
npm test                                  # 前端单元测试
npm run build                             # 生产构建
npm run preview                           # 预览构建产物
```
