# 参赛作品说明书（初稿）

作品名称：《非遗星图——国家级非物质文化遗产项目传承观察》
参赛赛道：全国大学生数字媒体科技作品及创意竞赛 · 自主命题
版本：v0.2.0-full（阶段A-D 完成稿）

## 一、项目背景

国家级非物质文化遗产是中华文化传承的重要载体。国务院自 2006 年起分五批公布国家级非遗代表性项目名录（含扩展名录），官方口径共 1557 项、3610 个地区子项；文化和旅游部另公布多批国家级代表性传承人。这些公开数据分散在名录、公文与网页中，公众难以直观理解“非遗分布在哪里、类别结构如何、传承资源覆盖如何”。

本项目以数字人文视角，将公开名录数据整理为可交互的“非遗星图”，为非遗认知、传播与研究提供低门槛的数据入口。

## 二、研究问题

1. 国家级非遗项目及子项主要分布在哪些地区？
2. 不同省级地区的类别结构有何差异？
3. 五批名录的新增与扩展如何变化？
4. 十大类别在空间与时间上的分布有何特点？
5. 各地区国家级代表性传承人公开配置是否相对充足？
6. 项目数量、类别多样性与传承人配置之间有何关系？
7. 用户如何通过地图、筛选、搜索与对比快速认识国家级非遗？

## 三、数据来源

- 主要来源：中国非物质文化遗产网（ihchina.cn）国家级非遗项目列表公开接口；
- 校验来源：国务院公布的五个批次名录通知及附件、文化和旅游部传承人名单（全量阶段）；
- 地图底图：DataV.GeoAtlas 中国省级 GeoJSON（仅作数据展示底图，非官方地图出版物）。

详见 `docs/数据源登记表.md`。

## 四、数据处理流程

1. 采集：低频率、指数退避重试、断点续传、原始响应归档、请求日志；
2. 清洗：编号/名称/地区/批次/类别标准化，保留原始字段；
3. 验证：编号格式、必填字段、重复、批次、类别、地区映射、类型校验 + 人工抽样；
4. 导出：前端本地 JSON（metadata/provinces/categories/batches/projects/subitems/search_index）。

## 五、技术架构

- 数据处理：Python 3.13、requests、pandas、tenacity、pytest；
- 前端：Vue 3、TypeScript、Vite、ECharts、Pinia、Vue Router；
- 部署：GitHub Pages（相对路径 + hash 路由，支持非根目录与断网演示）。

## 六、核心功能

1. 首页：动态关键指标与作品叙事；
2. 全国分布：省级地图、悬浮提示、点击联动、多条件筛选；
3. 寻找一项非遗：关键词搜索 + 多维度筛选 + 项目详情；
4. 数据与方法：数据来源、流程、指标与限制说明。

后续阶段：批次演化时间轴、十大类别星系、传承资源观察、省份对比实验室。

## 七、交互设计

- 地图与列表双向联动，筛选即时生效并可重置；
- 全链路空/载/错状态；移动端自适应；
- 图表悬浮提示、图例、单位与数据来源展示；
- 全部数据本地化，断网可用。

## 八、研究发现（全量数据，结论均可追溯）

1. 3610 个地区子项对应 1557 个独立项目，平均每个独立项目 2.32 个子项，印证“项目 ≠ 子项”的双重统计口径；
2. 跨地区项目典型：格萨(斯)尔覆盖 8 个省级地区、董永传说覆盖 5 省、梁祝传说覆盖 4 省；
3. 批次结构：第一批 763 条全部为新增；第二至第五批均含新增与扩展，扩展项目累计 1332 条；
4. 地区分布（按子项）：浙江 257、山东 186、山西 182、广东 165、河北 162、江苏 161 领先；
5. 类别结构：传统技艺子项最多（629），传统体育、游艺与杂技最少（166）；传统戏剧传承人覆盖最高（84.14%），民俗最低（40.24%）；
6. 传承人公开数据 3995 条（含 2025 年第六批 942 条），与子项匹配率 99.35%；
7. 各省“每百个子项对应传承人数”差异明显（江苏 141.0 vs 民俗类 46.9 等），仅反映公开配置结构，不作传承状况评价。

> 每条结论均附 对应指标/使用字段/筛选条件/数据版本/生成日期，见 `data/reports/conclusions.json`。

## 九、创新点

- 空间-时间-类别联动分析；

## 十、社会与文化价值

降低公众了解国家级非遗的门槛；为地方文化工作者与研究者提供可复用的数据观察入口；以数字人文方式讲好中国非遗故事，促进文化自信与传承传播。

## 十一、数据伦理与版权

- 仅使用公开数据，不绕过访问控制、不伪造数据、不高频请求；
- 不把缺失解释为不存在，不把相关描述为因果；
- 不使用未经支持的“濒危”表述；
- 地图底图与素材来源均登记授权范围；原始数据永久保留；
- 本项目为学术研究作品，非官方评价。

## 十二、项目局限

- 试点仅覆盖一个门类；传承人数据待全量阶段接入；
- 服务端关键词检索不稳定，采用前端本地检索；
- 构建体积因 ECharts 全量引入偏大，待按需引入优化。

## 十三、后续计划

1. 全量采集十大门类项目与子项（约 3610 条）；
2. 采集国家级代表性传承人名单并完成关联匹配；
3. 实现批次演化、类别星系、传承资源观察、省份对比；
4. 优化构建体积、完成移动端与部署验收；
5. 生成完整研究结论与视频演示。
