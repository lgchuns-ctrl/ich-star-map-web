## 五、数据限制与尚未解决的问题

1. 传承人接口无官方“是否在世”等状态字段，3995 条为公开名单记录口径；如需“在世/在世可查”口径需以文旅部最新通知核验。
2. 保护单位标准化仅做格式清洗；疑似同一单位的合并（如“××文化馆”与“××区文化馆（××非遗保护中心）”）需人工核验清单统一处理。
3. 传承人 26 条多候选记录未计入匹配率分子。
4. 官方文件（国务院批次附件、文旅部传承人通知）交叉核验尚未完成，仅以站点接口与公开汇总比对。
5. 服务端关键词检索不稳定，前端采用本地检索。
