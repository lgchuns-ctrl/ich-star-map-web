# 项目背景与竞赛调研

## 一、竞赛背景

本作品拟参加**全国大学生数字媒体科技作品及创意竞赛**（竞赛官网：[www.cmit.cn](http://www.cmit.cn)）。

### 往届信息（2025 年第十三届，调研时间 2026-08-06）

- 主办单位：中国人工智能学会、全国大学生数字媒体科技作品及创意竞赛组委会。
- 赛制：校赛 → 赛区赛（原省赛）→ 全国现场总决赛。
- 选题方式：**自主命题**与**指定命题**两大赛项。
- 团队要求：每队不超过 5 名学生，1–2 名指导教师或研究生组长，鼓励跨专业、跨学校组队。
- 时间安排（2025 年，供参考）：报名与作品提交截止约 9 月 21 日；校赛评审约 9 月下旬；全国总决赛约 11 月。
- 2026 年（第十四届）具体通知尚未发布，以上信息以官网后续通知为准。
- 来源：成都工业学院转发《2025年全国大学生数字媒体科技作品及创意竞赛通知》（2025-09）；辽宁工程技术大学等高校通知；竞赛官网 cmit.cn。

### 本作品的参赛定位

- 赛项：自主命题。
- 方向：数字人文 / 文化传承 / 数据可视化 / 交互设计。
- 呈现形式：可本地运行、可部署到 GitHub Pages 的交互式数据可视化网站，配套数据管道与完整文档。

## 二、项目目标

通过采集和整理**国家级非物质文化遗产代表性项目名录**（含扩展名录）与**国家级代表性传承人**公开信息，构建交互式非遗数据网站，回答七个核心问题（见 README）。

## 三、研究口径与概念区分

| 概念 | 说明 |
| --- | --- |
| 独立项目 | 国家级名录中拥有独立项目编号的条目（如 Ⅰ-1 苗族古歌） |
| 地区子项 | 同一项目在不同申报地区的记录（同一项目可对应多个子项） |
| 保护单位 | 项目申报时的保护单位（官方文件中明确列出） |
| 国家级代表性传承人 | 文化和旅游部公布的各批次国家级非遗代表性传承人 |
| 新增项目 | 名录首次公布的条目 |
| 扩展项目 | 后续批次纳入扩展名录的条目 |
| 项目公布批次 | 国务院公布名录的五个批次（2006/2008/2011/2014/2021） |
| 传承人公布批次 | 文化和旅游部公布代表性传承人的批次 |

## 四、禁止与允许的表述

### 禁止（未经官方数据支持）

- “濒危等级”“消亡风险”“保护失败”“传承状况差”
- 把“传承人数量较少”直接解释为“非遗濒危”

### 统一采用

- “传承资源关注度”
- “代表性传承人公开配置情况”
- “公开名录覆盖情况”

网页中必须明确声明：

> 相关指标基于公开国家级名录及国家级代表性传承人数据构建，仅反映公开数据中的资源配置与覆盖情况，不代表官方濒危等级或保护成效评价。

## 五、参考作品的方法借鉴（不抄袭）

参考作品《赛博词典》（[game_slang_dic](https://zbl1637.github.io/game_slang_dic/)）及其答辩 PPT《黑话.pptx》展示了如下可借鉴的方法链：

1. 真实数据采集；
2. 数据清洗与统计分析；
3. 交互式可视化；
4. 趣味互动功能；
5. 数据研究结论；
6. 文化价值叙事；
7. 完整网页呈现。

**本项目不复制**参考网站的页面布局、文案、图表、配色、动画、数据、交互逻辑与视觉素材，而是形成独立的视觉体系（星图/文化档案/现代东方美学）与独立研究问题。

## 六、总工作原则

官方来源优先、数据可追溯、不伪造数据、不伪造结论、缺失不当作不存在、相关性不作因果、不绕过访问控制、低并发礼貌采集、原始数据永久保留、清洗脚本化、人工修正留痕、网页离线可用、统计可溯源、素材来源授权可查。
