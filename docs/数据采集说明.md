# 数据采集说明（试点）

## 一、采集目标

试点阶段采集**中国非物质文化遗产网（ihchina.cn）国家级非遗项目列表接口**中「民间文学」门类的全部记录，用于验证：

1. 项目编号能否正确获取；
2. 项目名称、类别、批次、新增/扩展类型能否正确获取；
3. 申报地区/单位与保护单位能否获取；
4. 是否存在多地区、多子项情况；
5. 详情页能否稳定关联。

## 二、接口与参数

- 接口：`http://www.ihchina.cn/Article/Index/getProject.html`
- 请求方式：GET，返回 JSON
- 参数（已通过页面 JS 与实测确认）：

| 参数 | 含义 | 取值示例 |
| --- | --- | --- |
| category_id | 栏目 ID | 16（国家级非遗项目） |
| type | 门类 ID | 1=民间文学 … 10=民俗 |
| rx_time | 公布批次 ID | 1=2006(第一批)、2=2008(第二批)、3=2011(第三批)、4=2014(第四批)、10=2021(第五批) |
| cate | 类型 ID | 1=新增项目、2=扩展项目 |
| province | 省级行政区代码 | 110000=北京市、990121=中直单位、990122=新疆生产建设兵团 |
| keywords | 关键词 | 项目名称（本接口行为不稳定，试点未依赖） |
| limit / p | 每页条数 / 页码 | limit 实测可到 100 及以上 |

## 三、采集行为约束

- 合理 User-Agent 与 Referer；
- 请求间隔默认 1.2 秒，失败时指数退避（1s/2s/4s…最大 30s），最多重试 3 次；
- 超时 30 秒；断点续传（已归档页面不再请求）；本地缓存；
- 原始响应按参数哈希归档到 `data/raw/projects/pages/`；
- 请求日志 `data/raw/request_logs/request_log.csv`；
- 失败记录 `data/raw/projects/failed_records.jsonl`；
- 重复检测按记录 id 去重；
- 支持 `--dry-run` 与 `--no-resume`。

## 四、本次实际采集

```bash
python scripts/collect/collect_ihchina.py --scope category --value 1 --max-records 300
```

- 请求 3 次，成功 3 次，失败 0 次；
- 共 251 条原始记录（民间文学门类全量），归档于 `data/raw/projects/projects_raw.jsonl`；
- 每条原始记录包含：原始来源、原始 payload、采集时间、页码/参数、原始记录编号、内容哈希。

## 五、已知问题

1. `keywords` 参数在该接口下行为不稳定（实测同参数两次返回不同结果），试点阶段不依赖服务端检索，搜索在前端本地完成。
2. 试点仅覆盖「民间文学」门类（251 条），不代表全国 3610 条子项总量；全量阶段将按门类/批次/地区组合采集。
3. 详情页 URL 格式为 `/project_details/{id}.html`（已实测 200），用于全量阶段补全简介与图片。
